# ADR-0000: Architecture decision record template

- Status: template
- Date: YYYY-MM-DD
- Owners:

## Context

What problem are we solving? What constraints, threats or requirements matter?

## Decision

What did we decide? Be specific enough that someone can implement it.

## Consequences

What becomes easier, harder, safer or riskier? Include follow-up work and residual risks.

## Alternatives considered

What else did we consider, and why did we reject it?
